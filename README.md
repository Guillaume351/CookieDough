# CookieDough

**CookieDough** is the core plugin for recreating the original Cookie Build mini-game Minecraft server on a new platform, based on *PaperMC*, *Geyser*, and *Floodgate*.

## Requirements

- Java 25
- Paper 26.1.2 build 74 or newer 26.1.2 build

Build the shaded plugin with:

```shell
./gradlew clean build
```

The resulting JAR is written to `build/libs/`.
